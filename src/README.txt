LaptopCheck - used laptop inspection / 중고 노트북 점검
=========================================================

[한국어]
1. 이 폴더 전체를 USB에 복사합니다. (압축을 꼭 풀어야 합니다)
2. 점검할 노트북에 USB를 꽂고 START.bat 를 더블클릭합니다.
   - "Windows의 PC 보호" 창: [추가 정보] -> [실행]
   - 관리자 권한(UAC) 창: [예]  (SSD 상세 수명 확인용)
3. 30초 뒤 브라우저가 열리면 오른쪽 위에서 "빠른 점검"을 고르고
   왼쪽 메뉴를 위에서부터 진행합니다.
4. 마지막 "최종 결과"에서 [결과 텍스트 복사]로 저장해 두세요.
- 읽기 전용입니다. 설정을 바꾸거나 설치·삭제하지 않고, 네트워크로 아무것도 보내지 않습니다.
- macOS: LaptopCheck.html 을 브라우저로 열면 수동 테스트만 쓸 수 있습니다.

[English]
1. Copy this whole folder to a USB stick (extract the ZIP first).
2. On the laptop you are checking, double-click START.bat.
   - "Windows protected your PC": More info -> Run anyway
   - UAC prompt: Yes (for detailed SSD health)
3. When the browser opens, choose "Quick" at the top right and
   work down the menu on the left.
4. On "Result", click "Copy result text" to keep a record.
- Read-only: changes no settings, installs nothing, sends nothing over the network.
- macOS: open LaptopCheck.html in a browser for the manual tests only.

Source & updates: see the project's GitHub page.
