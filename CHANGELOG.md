# Changelog

## v1.0.0 — 2026-10-09

First public release.

- One-click, read-only, offline check for any Windows 10/11 laptop (`START.bat`)
- Automatic: battery health and cycles, SSD health/wear/power-on hours, 90-day crash history, device errors, touchscreen/touchpad/webcam/audio/Wi-Fi/Bluetooth detection, activation, drive encryption
- Listing comparison: model, CPU, RAM, storage, claimed battery health, touchscreen
- Guided manual tests: color screens, keyboard map, touch grid, touchpad gestures, stereo speakers and sweep, microphone level, webcam, live charging status, CPU load test
- Quick (~5 min) and Full (~12 min) modes
- Korean and English UI
- Result: verdict, copyable text (serial masked), JSON report, print/PDF
